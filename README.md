## AI Coding Agents & IDEs

- [Cursor](https://cursor.com) - AI-native code editor built for agentic coding workflows.
- [Windsurf](https://windsurf.com) - Agentic IDE (formerly Codeium Cascade) for multi-file AI edits.
- [GitHub Copilot](https://github.com/features/copilot) - AI pair programmer inside VS Code, JetBrains, and more.
- [Claude Code](https://claude.ai/code) - Anthropic’s agentic coding assistant in the terminal and IDE.
- [Devin](https://devin.ai) - Autonomous software engineer agent from Cognition.
- [Aider](https://aider.chat) - Open-source AI pair programming in your terminal, git-aware.
- [Continue](https://continue.dev) - Open-source autopilot for VS Code and JetBrains.
- [Cody](https://sourcegraph.com/cody) - Sourcegraph’s AI coding assistant with codebase context.
- [Tabnine](https://www.tabnine.com) - AI code completion with privacy-focused options.
- [Replit Agent](https://replit.com) - Build and deploy apps from natural language inside Replit.

## App Builders & Prototyping

- [v0](https://v0.dev) - Vercel’s generative UI for React / Next.js from prompts.
- [Lovable](https://lovable.dev) - Chat-to-app builder for full-stack web products.
- [Bolt.new](https://bolt.new) - StackBlitz’s in-browser AI app builder.
- [Create.xyz](https://www.create.xyz) - Prompt-to-app platform for shipping quickly.
- [DhiWise](https://www.dhiwise.com) - Design-to-code and AI app generation workflows.
- [Softgen](https://softgen.ai) - AI full-stack app builder for founders.
- [Tempo](https://www.tempo.new) - Visual React editor with AI assistance.

## Models & Inference

- [OpenAI](https://openai.com) - GPT models and APIs for chat, vision, and agents.
- [Anthropic](https://www.anthropic.com) - Claude models for coding, writing, and agents.
- [Google Gemini](https://deepmind.google/technologies/gemini/) - Multimodal models and Google AI Studio.
- [Groq](https://groq.com) - Ultra-fast LLM inference.
- [Together AI](https://www.together.ai) - Hosted open models and fine-tuning.
- [Fireworks AI](https://fireworks.ai) - Fast inference for open-source models.
- [Mistral AI](https://mistral.ai) - Open and commercial frontier models.
- [DeepSeek](https://www.deepseek.com) - Strong coding and reasoning models with APIs.
- [Ollama](https://ollama.com) - Run open models locally with a simple CLI.
- [Hugging Face](https://huggingface.co) - Models, datasets, Spaces, and inference endpoints.

## Design & UI

- [Figma](https://www.figma.com) - Collaborative design; pairs well with AI plugins and codegen.
- [Framer](https://www.framer.com) - Design and ship marketing sites with AI help.
- [Relume](https://www.relume.io) - AI site structure and Webflow / Figma components.
- [Galileo AI](https://www.usegalileo.ai) - Text-to-UI design generation.
- [Excalidraw](https://excalidraw.com) - Hand-drawn style diagrams for product thinking.
- [tldraw](https://tldraw.com) - Infinite canvas; useful for AI + whiteboard workflows.

## Backend, Auth & Infra

- [Supabase](https://supabase.com) - Postgres, auth, storage, and edge functions for indie apps.
- [Firebase](https://firebase.google.com) - Google’s backend suite for auth, DB, and hosting.
- [Clerk](https://clerk.com) - Drop-in authentication and user management.
- [Neon](https://neon.tech) - Serverless Postgres.
- [Vercel](https://vercel.com) - Frontend cloud for Next.js and AI apps.
- [Railway](https://railway.app) - Simple deploy platform for full-stack apps.
- [Render](https://render.com) - Hosting for web services, workers, and databases.
- [Cloudflare Workers](https://workers.cloudflare.com) - Edge compute and AI bindings.
- [Stripe](https://stripe.com) - Payments for SaaS and usage-based products.
- [Resend](https://resend.com) - Email API for product transactional mail.

## Contribute

PRs welcome. Please:

1. Keep entries **English**, one line each: `[Name](url) - short description.`
2. Place tools in the most relevant section (or propose a new section).
3. Prefer products that vibe coders / AI builders actually use to ship.
4. No affiliate spam or unrelated crypto/NFT dumps.
